# Jumbo810/Upload_Github_Artifacts_TO_GDrive

Automates secure CI/CD artifact backups to Google Drive. Features per-file retention, auto-sharing, smart format conversion, and zero-config privacy.

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/Jumbo810/Upload_Github_Artifacts_TO_GDrive](https://github.com/Jumbo810/Upload_Github_Artifacts_TO_GDrive).
